# タスク管理アプリ

個人のタスクをカンバンボードで管理するWebアプリです。  
「やること / やってる最中 / 完了」の3ステータスでタスクを管理できます。

---

## 機能

| 機能 | 説明 |
|------|------|
| タスク作成 | タスク名を入力して追加できる |
| カンバンボード表示 | 「やること」「やってる最中」「完了」の3列で表示 |
| ステータス移動 | リスト間でカードをドラッグ＆ドロップで移動できる |
| 並び替え | 同じリスト内でドラッグ＆ドロップで順序変更できる |
| タスク削除 | 不要なカードを削除できる |

## 起動方法

### 前提条件

- Java 21
- Node.js / pnpm
- Docker

### 1. データベース起動

```bash
docker compose up -d
```

### 2. バックエンド起動

```bash
cd backend
./mvnw spring-boot:run
```

### 3. フロントエンド起動

```bash
cd frontend
pnpm install
pnpm dev
```

ブラウザで http://localhost:5173 を開く。
