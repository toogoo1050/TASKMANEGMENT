# Git 学習メモ

## git pull とは

GitHub（リモート）→ 自分のPC（ローカル）へ、最新の変更をダウンロードする操作。

```
GitHub (リモート)          自分のPC (ローカル)
─────────────────          ─────────────────────
main: ★最新               main: ☆古い状態のまま
         ↓ git pull
main: ★最新               main: ★最新 ← 同期された！
```

## プルリクエスト（PR）とは

「このブランチをmainにマージしてください」という**申請・お願い**のこと。  
`git pull` とは別物！名前が紛らわしいだけ。

## ブランチとは

ファイルの入れ物ではなく、**コミット（変更履歴）の流れ**。

```
main:    A → B → C
                  ↘
feature:            D → E（作業中）
```

ブランチを切り替えると、ファイルの中身がその時点の状態に変わる。  
→ **「どの時点の状態を見るか」の切り替えスイッチ**

## ブランチの種類

| ブランチ名 | 用途 |
|-----------|------|
| `main` | 本番用・常に動く状態を保つ |
| `feature/...` | 新機能を追加するときの作業用 |
| `fix/...` | バグ修正するときの作業用 |
| `docs/...` | ドキュメント変更するときの作業用 |

## 正しい開発フロー

```
① イシュー作成（GitHub上で「こんな作業するよ」と宣言）
② ブランチを切る
   git checkout main
   git pull
   git checkout -b feature/issue-3-xxx
③ 作業・コミット・プッシュ（ブランチ上で）
④ PR作成（GitHub上で「mainにマージして」と申請）
⑤ マージ（GitHub上でボタンポチ）
⑥ ローカルをmainに戻してpull（PCを最新に同期）
   git checkout main
   git pull
```

## セットで覚えるコマンド

```bash
git checkout main  # mainに切り替え
git pull           # mainの最新を取得
```

次の作業のブランチを**mainの最新状態から**切るために、毎回この2行がセット。
