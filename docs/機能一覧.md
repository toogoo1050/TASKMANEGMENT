# 機能一覧

## 機能

| 機能 | 説明 |
|------|------|
| カードを作る | タスク名を入力して追加できる |
| リストを3つ表示 | 「やること」「やってる最中」「完了」 |
| カードを移動 | リスト間でカードを動かせる |
| カードを並び替え | 同じリスト内でドラッグ＆ドロップで順序変更できる |
| カードを削除 | 確認モーダルを経て削除できる |
| カードを編集 | 編集モーダルでタイトル・ステータス・優先度・期限日・カテゴリ・メモを変更できる |
| 優先度設定 | 高 / 中 / 低 の優先度をカードに設定できる |
| 期限日設定 | 期限日を設定でき、過ぎたカードは赤表示になる |
| カテゴリ設定 | 自由入力でカテゴリをカードに付与できる |
| メモ | 補足メモをカードに追加できる |
