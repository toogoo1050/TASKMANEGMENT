# 機能要件

## ユースケース

アクター：ユーザー（自分）

- タスクを追加する
- タスクをステータス移動する
- タスクをリスト内で並び替える
- タスクを削除する
- タスクを編集する
- タスク一覧を確認する

## 各機能の要件

### タスク追加

- タスク名（title）を入力して追加できる
- 追加されたタスクは「やること」ステータスで作成される
- 追加時に id と createdAt が自動生成される
- 追加後、編集モーダルで優先度・期限日・カテゴリ・メモを設定できる

### ステータス移動

- カードをドラッグ＆ドロップで別リストに移動できる
- 移動先のステータス（"todo" / "doing" / "done"）に更新される

### カード並び替え

- 同一リスト内でカードをドラッグ＆ドロップで並び替えられる
- ドラッグ中は挿入位置を示すラインが表示される（カード上半分で上、下半分で下）
- 並び順はサーバーに保存され、ページ再読み込み後も維持される

### タスク削除

- 削除ボタンを押すと確認モーダルが表示される
- 確認モーダルで「削除する」を押すと削除される

### タスク編集

- 編集ボタン（✎）を押すと編集モーダルが開く
- 編集できる項目：タイトル・ステータス・優先度（高/中/低）・期限日・カテゴリ・メモ
- 保存ボタンで変更が確定される
- キャンセルまたは Escape キーでモーダルを閉じる

### タスク一覧表示

- 3列のリストにステータスごとのカードを表示する
- ページ読み込み時にサーバー（PostgreSQL）からデータを取得する
- 優先度バッジ・期限日を各カードに表示する（設定済みの場合）
- 期限切れのカードは期限日を赤字で表示する
