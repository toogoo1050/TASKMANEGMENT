# 機能要件

## ユースケース

アクター：ユーザー（自分）

- タスクを追加する
- タスクをステータス移動する
- タスクをリスト内で並び替える
- タスクを削除する
- タスク一覧を確認する

## 各機能の要件

### タスク追加

- タスク名（title）を入力して追加できる
- 追加されたタスクは「やること」ステータスで作成される
- 追加時に id と createdAt が自動生成される

### ステータス移動

- カードをドラッグ＆ドロップで別リストに移動できる
- 移動先のステータス（"todo" / "doing" / "done"）に更新される

### カード並び替え

- 同一リスト内でカードをドラッグ＆ドロップで並び替えられる
- ドラッグ中は挿入位置を示すラインが表示される（カード上半分で上、下半分で下）
- 並び順は localStorage に保存され、ページ再読み込み後も維持される

### タスク削除

- 削除ボタンを押すと即座に削除される
- 確認ダイアログは表示しない

### タスク一覧表示

- 3列のリストにステータスごとのカードを表示する
- ページ読み込み時にlocalStorageからデータを復元する
